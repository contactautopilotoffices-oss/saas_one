 QUICK Q&A  (sanity answers while testing)
==============================================================================
 Q: Nothing shows in "To Align"?
 A: No POs yet. Add one manually (2.1), import CSV (2.2), or sync Zoho (3.2).
    Only POs with pending (un-aligned) amount > 0 appear there.

 Q: I don't see the "Zoho" / "Add PO" / "Align" buttons.
 A: Those need canAlign (procurement/accounts/admin). A pure viewer won't see
    them. "Mark paid" needs the accounts role.

 Q: Emails aren't arriving.
 A: Expected until SMTP_* env is set. The flow itself still works; email is
    best-effort and silently skipped without SMTP.

 Q: Sync says "missing credentials".
 A: Set ZOHO_CLIENT_ID / ZOHO_CLIENT_SECRET / ZOHO_REFRESH_TOKEN and restart.
    The org id (807372318) is separate and set in the Zoho panel.

 Q: A user sees the wrong petty-cash rows.
 A: Check their role -> which tab. Mine=own only; Approvals/Disbursements need
    approver/finance; All is scoped for non-admins to own+own-properties.

 Q: There are TWO Zoho orgs named "Parsvatech Workspaces Private Limited".
 A: Use the DEFAULT one = 807372318 (live POs). The other (829011181) is a
    legacy/sandbox org — skip it.
